# MacTele

Неофициальный клиент Telegram для Windows с интерфейсом, повторяющим Telegram для macOS:
цвета, размеры, шрифт, анимации, «парящая» панель вкладок, меню и всплывающие подсказки (HUD).

## Как это устроено

| Часть | Что делает |
|---|---|
| **TDLib** (`tdjson.dll`) | Официальная библиотека Telegram: вход, шифрование MTProto, секретные чаты, локальная база. |
| **Rust / Tauri** (`src-tauri/`) | Окно программы, загрузка TDLib, хранение ключей в «Диспетчере учётных данных» Windows. |
| **Интерфейс** (`ui/`) | HTML/CSS/JS без сборщиков; Preact и htm лежат в `ui/js/vendor`. |

### Безопасность
- Переписка идёт напрямую между компьютером и серверами Telegram — без посредников.
- Локальная база TDLib зашифрована случайным 256-битным ключом. Ключ, а также `api_id` и `api_hash`
  хранятся в «Диспетчере учётных данных» Windows, а не в файлах.
- Интерфейс не может сам задать параметры базы или ключ: это делает только Rust-часть.
- Строгая политика CSP: страница не загружает ничего из интернета.

## Установка
1. Откройте вкладку **Releases** → «Последняя сборка» и скачайте файл `MacTele_..._x64-setup.exe`.
2. Запустите его. Windows может показать «Windows защитила ваш компьютер» — нажмите
   **Подробнее → Выполнить в любом случае** (программа не подписана платным сертификатом).
3. При первом запуске введите `api_id` и `api_hash` с сайта <https://my.telegram.org> → *API development tools*.

## Сборка
Каждый коммит в `main` автоматически собирается GitHub Actions (`.github/workflows/build.yml`)
и публикуется в Releases как «Последняя сборка».

Посмотреть интерфейс без TDLib можно в браузере: запустите любой локальный сервер в папке `ui`
и откройте `index.html?mock=ready` (демо-данные), `?mock=auth` (экран входа, код `12345`, пароль `demo`).

## Что умеет (версия 0.2)
- Вход: номер, код, облачный пароль, почта; ключи и ключ базы — в «Диспетчере учётных данных» Windows
- Новый дизайн Telegram для macOS (Liquid Glass): обои аккаунта, плавающая карточка списка,
  стеклянные шапка и поле ввода, настоящие иконки из Mac-версии, темы Day Classic / День / Ночь
- Чаты: папки, архив, поиск (Ctrl+K), истории, закреп, «печатает…», миниатюры, секретные чаты
- Сообщения: текст с разметкой, ответы, правка, удаление, пересылка, выбор нескольких, реакции,
  закреп, поиск по чату (Ctrl+F), переход к любому сообщению, альбомы, превью ссылок, опросы
- Медиа: фото, видео (свой плеер), GIF, стикеры (в т.ч. анимированные), голосовые (запись и
  прослушивание), кружочки, музыка (плеер со скоростью и громкостью)
- Отправка: файлы, фото и альбомы (скрепка, перетаскивание, Ctrl+V), эмодзи, стикеры, GIF
- Профиль собеседника, создание групп и каналов
- Настройки: аккаунт и фото, уведомления, конфиденциальность, активные сеансы, оформление, память
- Уведомления Windows и счётчик на значке

## Пока нет

- Темы форумов, боты с кнопками, управление группами (права, участники)
