# Иконки

Иконки в этой папке взяты из исходников Telegram для macOS
(https://github.com/TelegramMessenger/telegram-macos, `Telegram-Mac/Assets.xcassets`),
которые распространяются по лицензии GNU GPL версии 2. Одноцветные иконки преобразованы
в маски (белый цвет + прозрачность), чтобы их можно было окрашивать цветом темы.
